部署到 Cloudflare Workers

LX API Server 的 Workers 版：QQ 音乐、酷狗音乐、网易云音乐解析，自带管理后台。

★最简单：一键部署

不需要安装任何东西。点击按钮，登录 Cloudflare 并连接 GitHub，填写管理后台密码 ADMIN_PASSWORD，点击部署即可。数据库会自动创建。

部署完成后打开 https://….workers.dev/admin，用户名 admin，然后从第 4 步继续。下面是用部署脚本的方式。

1准备环境

安装 Node.js 20 或更高版本，注册一个 Cloudflare 账号(免费版即可)。

2运行部署脚本

在项目目录里运行，脚本会安装依赖、登录 Cloudflare、创建 D1 数据库并部署：

./deploy.sh          # Linux / macOS
deploy.bat           # Windows

最后会询问管理员密码，直接回车可以跳过，稍后在网页上创建。

3打开管理后台

访问部署输出里的 https://….workers.dev/admin。如果刚才没有设置密码，页面会提示创建管理员账号。

4登录音乐账号、创建用户

在“音乐账号”页扫码登录 QQ 音乐或网易云音乐(保存时勾选自动刷新登录)；在“用户”页新建用户，把音源脚本链接发给使用者。

5在 LX Music 中导入

LX Music →「设置」→「自定义源」→「在线导入」，粘贴：

https://你的地址/script?key=用户的Key
升级：拉取新代码后再运行一次部署脚本即可，数据库表结构会自动升级，旧版的配置会自动迁移。 手动部署和更多说明见 README。
