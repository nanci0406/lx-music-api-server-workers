全球加速
⚠️ 部署前准备 需要一个 Cloudflare 账号（免费即可）
1

Fork 项目到你的 GitHub

点击下方按钮，将项目 Fork 到你的 GitHub 账号

2

安装 Wrangler CLI

在本地安装 Cloudflare Wrangler 工具

npm install -g wrangler
3

登录 Cloudflare

使用 Wrangler 登录你的 Cloudflare 账号

wrangler login
4

创建 D1 数据库

创建数据库并记录 database_id

wrangler d1 create lx-music-api-db
5

更新配置文件

将 database_id 填入 wrangler.toml 文件

[[d1_databases]]
binding = "DB"
database_name = "lx-music-api-db"
database_id = "你的数据库ID"
6

初始化数据库

执行数据库迁移脚本

wrangler d1 execute lx-music-api-db --remote --file=./src/db/schema.sql
7

部署到 Cloudflare Workers

运行部署命令

npm install && npm run deploy
8

访问管理后台

部署成功后，访问 your-worker.workers.dev/admin

默认账号：admin / admin123
